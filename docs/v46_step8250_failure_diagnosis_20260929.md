## Audit protocol

The main audit runs on **all 256 paired train/dev cases**, each exactly once,
at native 1024×768 image resolution. All samplers see the same per-case Gaussian
noise, agnostic person, pose and correct garment. Sampling uses CFG 1, time
shift 1, the configured mask opening, seam correction and eight-call dual-loop
parameters. The comparison is dual-loop 8 calls, Euler 8 calls and Euler 50
calls. The frozen VAE reconstructs the target image as a representation
baseline. Metrics use equal weight per image and RGB in [-1, 1]. The clothing,
edit and target-derived contrast masks are the same for every sampler.

The existing `scripts/audit_pfi_timesteps.py` was corrected before the run to
respect the evaluation time shift and seam settings, validate pair
fingerprints, and label time profiles with actual shifted sampler times. A
regression test for the time-axis calculation passed on the server (seven audit
tests total). The run used a fixed seed of 12345 and completed in about 29
minutes. Selected 32 cases, including all eight preview cases, received
teacher-state and actual-rollout error profiles. Those 32 are a diagnostic
subset, **not** the full 256 cases. Contrast masks are based on deviation from
the target shirt's base color; they are not OCR or a text-recognition score.

The checkpoint's stored fit/dev fingerprints match the active paired files:
11,391 fit identities and 256 separate dev identities. This audit therefore
does not repeat the earlier cross-pair data error.

Lower is better except clothing SSIM. Values are equal-per-image means, so
they should not be compared directly to older batch-area-weighted preview logs.

| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Dual-loop | 8 | **0.17063** | **0.14119** | **0.05716** | **0.34856** | **0.61544** |
| Euler | 8 | 0.17419 | 0.14469 | 0.05869 | 0.35131 | 0.60542 |
| Euler | 50 | 0.19029 | 0.15767 | 0.06564 | 0.36780 | 0.57044 |
| VAE reconstruction of true image | 0 | 0.04770 | 0.03795 | 0.03951 | 0.07981 | 0.85408 |

Across the same 256 cases, Euler 8 has clothing L1 **0.00356** above dual-loop
8 (paired bootstrap 95% interval **[0.00298, 0.00416]**), and dual-loop 8 wins
on **207/256** cases. Euler 50 has clothing L1 **0.01966** above dual-loop 8
(paired bootstrap interval **[0.01764, 0.02171]**); dual-loop wins on
**235/256** cases. Euler 50 has worse clothing high-pass L1 on all 256 cases.
The bootstrap intervals describe variation over these paired dev cases and a
single fixed noise seed; they do not include other seeds or the official test
split. This is strong evidence against increasing Euler steps as the immediate
fix for this checkpoint.

The VAE reconstructed lettering, broad garment shape and people much more
faithfully in the selected images. Its clothing L1 of 0.04770 is substantially
below the generated 0.17063, although VAE high-pass error of 0.03951 is not
zero. The VAE imposes some detail loss, but it is **not the principal source**
of the observed text and logo failures. Selected Lee, GAP, FILA and Wrangler
outputs show that 50 Euler calls may make individual strokes more visible yet
often drift in color, garment shape or placement. These visual observations
are supported by the full-dev aggregate error, rather than replacing it.

## Where the trajectory diverges

The time-profile experiment evaluates the same model both on a
ground-truth interpolation state and on the state generated by Euler from
noise. It assesses how a training-like state differs from actual inference.

| Time | Teacher-state clothing endpoint L1 | Euler-8 rollout clothing endpoint L1 | Euler-50 rollout clothing endpoint L1 |
| ---: | ---: | ---: | ---: |
| 0.00 | 0.1829 | 0.1829 | 0.1829 |
| 0.50 | 0.0887 | 0.1869 | 0.1956 |
| 0.875 / 0.88 | about 0.057 | 0.1885 | 0.2022 |
| 0.98 | 0.0541 | — | 0.2032 |

The main issue appears early: a rollout from noise does not approach the
training-like trajectory, and additional small Euler steps accumulate rather
than repair the error. The teacher-state endpoint gets easier *mechanically* as
time approaches one because the state itself contains an increasing fraction
of the true target. Its falling loss must **not** be read as proof that the
late-time model would fix an actual rollout. Teacher velocity MSE on these
32 cases actually rises from 0.468 at time zero to about 1.027 at time 0.98.
The uncertainty/error rank correlation also weakens near time one. These
observations identify a discrepancy between training-state and inference-state
behavior; they do not by themselves prove a unique architectural cause.

## Does the model use the garment?

An additional fixed-seed intervention on the eight preview people used the
same model, person, pose and noise, changing only the garment latent and its
mask. Every person was paired with a deliberately different garment from
another preview case. The absent-garment condition uses zero latent and mask.

| Garment condition | Clothing L1 ↓ | Edit L1 ↓ | Contrast L1 ↓ |
| --- | ---: | ---: | ---: |
| Correct garment | **0.17137** | **0.12560** | **0.44993** |
| Garment from another case | 0.71076 | 0.39415 | 0.69873 |
| Garment absent | 0.70335 | 0.36368 | 0.54613 |

The image changes decisively with the garment: for example, the GAP person
wears a turquoise Wrangler-style shirt when supplied that garment, and the
FILA person wears the swapped graphic T-shirt. This rejects the explanation
that the model simply ignores garment input. Correct-shirt text and small
shape features are still malformed. This intervention is deliberately small
and uses a VTON target metric that rewards the original shirt; it establishes
dependency on the conditioning input, not accurate lettering for arbitrary
cross-person try-on. Its image is in the ignored local file
`logs/server-audit-20260929/matched-swapped-absent.jpg`.

The retained update-3250 checkpoint was evaluated on exactly the same eight
preview pairs, seed, samplers and masks as update 8250:

| Checkpoint | Dual-loop 8 clothing L1 ↓ | Dual-loop 8 high-pass L1 ↓ | Target-derived contrast L1 ↓ |

Only two of the eight preview cases improve in clothing L1 by update 8250.
Contrast L1 moves in the other direction, but this proxy does not say whether
letter identities became correct. Eight preview cases cannot rank the
checkpoints over the full development set. The previously logged best preview
was update 4750, but its weights were not retained because the 24 GB free-space
threshold skipped numbered snapshots on this 64 GB instance. The exact
update-4750 model cannot be audited now.

## Interpretation and next experiment

The supported diagnosis is **sampling-trajectory drift plus incomplete
fine-detail learning**, with strong but imperfect garment conditioning.
This is an inference from the matched long-step results, VAE baseline,
time profiles and garment intervention, not a claim that a single code line
has been proven faulty. The current code trains velocity and decoded-detail
loss mainly on interpolations containing the true target. Its decoded loss
requires editable mean time ≥0.65, is applied with probability 0.5, and is
capped at one image per four-image microbatch. Recent logs average about
0.59 selected images per microbatch, approximately 15% of image exposures.
At late times, the decoded endpoint also depends less on the predicted
velocity through the `(1-t)` factor. This design is a plausible contributor
to the measured gap between training-like states and rollouts.

For the next bounded research experiment, preserve the current checkpoint and
run a small, separate training branch that adds masked endpoint/RGB and
high-pass supervision on **actual, detached rollout states at early and
middle times**, along with correctly paired garment input. Increase decoded
supervision exposure only after checking VRAM. Compare this branch with an
otherwise identical continuation from update 8250 on fixed dev cases, and
measure both eight-call quality and the teacher-versus-rollout gap. Avoid
relying on more Euler steps or an unpaired garment list. OCR with human-checked
labels would be needed to make a claim about exact text identity.
